# 角色立繪基礎畫風

## 生成後端限制

- 本專案禁止使用 ComfyUI 生成、重生成或驗收角色立繪；不得啟動、接入或以 `127.0.0.1:8188` 作為本專案的角色美術生成後端。
- 本專案既有支線角色的六表情生成路徑是 `anime-expression-grid` → 內建 `imagegen`；這不是 ComfyUI，也不要求本機生成後端。主線角色立繪應沿用同一條路徑，除非使用者另行指定其他工具。

本專案 AVG 角色立繪以「簡化日本動漫立繪」為基礎風格。生成或重繪角色時，先抽取角色身份要素，再套用本文件的畫風規則；不要直接複製參考圖姿勢或服裝錯誤。

## 基礎風格

- 畫面類型：全身 AVG 立繪、單人、站姿。生成母圖必須是純綠幕背景；完成分格與 `remove_bk.py` 去背後，runtime 才使用透明背景 PNG。
- 線條：乾淨粗黑線，輪廓清楚，髮絲與服裝內線可細一些，但避免草稿線、厚塗筆觸和雜訊。
- 上色：平面賽璐璐上色，色塊乾淨，陰影少量且邊界明確；不要水彩、油畫、厚塗、寫實光影或複雜漸層。
- 比例：日本動漫 Q 版偏修長，頭身略低於一般寫實比例，四肢簡化，手部不用過度細節。
- 表情：眼睛大且清楚，嘴鼻簡化，表情差分用眉眼和嘴型的小改動完成。
- 母圖構圖：角色完整入鏡，腳底可見，左右留出頭髮與衣襬空間；六格母圖的每個人物都必須與四周格線保持至少 5% 綠幕 gutter，任何頭髮、手、衣物或腳都不得碰到或跨過分格線。
- 參考圖硬規則：開始生成前必須先從本次 ZIP 的 `raw/` 找到該角色的實際參考圖並完成特徵核對；角色名稱、職業、劇本文字與檔名都不具備替代參考圖的價值。ZIP 原圖無論是否已是完整站立立繪，都只能作為角色身份與外觀特徵的生成參考，絕對不得直接複製、改名、裁切或放入正式立繪位置。正式交付必須重新生成該角色的六種表情差分：`smile`、`angry`、`sad`、`surprised`、`panic`、`normal`。
- 遊戲內構圖：母圖／切圖保留完整可用身體，由共用 AVG layout 放大並把人物底部錨定到畫面外，使可見人物頂端約落在畫面上緣下方 20% 的位置；腳與下半身超出畫面、被底部裁切屬正常現象。不得為了取景先裁掉 runtime PNG 的腿腳，也不得建立角色專用縮放或座標。
- 背景：生成中間稿使用純色 chroma key 背景，最終交付必須是真 alpha 透明 PNG。

## 色彩規則

- 主色以高對比色塊為主，常用白、紅、黑與少量紫色眼睛高光。
- 避免複雜材質、金屬裝甲、寫實布料紋理、灰階髒污和照片感光影。
- 角色身份色應優先於模型自行添加的飾品色；不需要的貓耳、獸耳、裝甲、披風應明確排除。


## 負面約束

生成時排除：

- 厚塗、水彩、油畫、鉛筆草稿、髒污筆觸。
- 白底或假透明棋盤格作為最終輸出。

## 交付規則

- 每個角色至少保留 `neutral`、`smile`、`serious`、`surprised` 四張差分。
- 高解析中間稿與生成 metadata 放在 `art/characters/<character-id>/`。
- 遊戲用透明 PNG 放在 `project/images/`，並加入 `project/data.js -> main.images`。
- 交付前用 `validate_png_alpha.py` 驗證所有最終 PNG 有真透明像素。
- 六格切圖使用 `split_emotion_image.py` 的綠幕 gutter 偵測；不得用固定 inset 掩蓋跨格內容。若偵測不到連續安全 gutter，先修正母圖再切圖。
